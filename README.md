# Sentir

Static copy of [sentir.pe](https://sentir.pe) — Sentir Consultorio Psicológico.

Mirrored from the live WordPress/Elementor site: all pages (home, nosotros, therapy pages, summer workshops, blog + posts) plus their CSS, JS, fonts, images and videos. URLs are rewritten to relative paths, so it works from any static host.

## Run locally

```bash
npx serve .
```
